## 指标说明

| 指标 | 含义 |
|---|---|
| **严格准确率** | 预测与 Gold 判定为 `exact` 的比例 |
| **宽松准确率** | 判定为 `exact + partial` 的比例 |
| **Macro F1** | 归一化词元上的逐题 F1 宏平均 |
| **成本** | 根据保存的 prompt/response 字符数估算；不包含供应商缓存折扣 |

## 实验配置

- LLM：`deepseek-chat`。
- 三个模型统一使用 New Model 的 LLM Judge，将预测判为 `exact`、`partial` 或 `miss`。
- 所有系统均使用 question-bound Table 及其链接 Doc，不启动全局 Table/Doc 检索服务。
- Token 估算采用 `字符数 ÷ 4`；输入 $0.28/百万 token，输出 $0.42/百万 token。
- `—` 表示该次运行没有保存对应 trace 或计时信息。
